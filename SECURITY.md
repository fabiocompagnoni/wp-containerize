# Politica di sicurezza

## Segnalare una vulnerabilità

Non aprire issue pubbliche per problemi di sicurezza. Usa invece le
**GitHub Security Advisories** del repository: scheda *Security*, poi
*Report a vulnerability*. La segnalazione resta privata fino alla correzione.

Indica, se possibile, versione interessata, passi per riprodurre il problema e impatto
stimato. Non includere dati reali di siti, clienti o credenziali.

## Ambito

Il tool tratta il codice estratto dai siti come dato non fidato. Sono di particolare
interesse le falle che permettano di eseguirlo fuori da un container, di scrivere sulla
sorgente o di far trapelare segreti.

# Security policy

## Reporting a vulnerability

Do not open public issues for security problems. Use the repository's
**GitHub Security Advisories** instead: *Security* tab, then *Report a vulnerability*.
The report stays private until a fix is released.

If possible, include the affected version, steps to reproduce and the estimated impact.
Do not include real site data, customer data or credentials.

## Scope

The tool treats code extracted from sites as untrusted data. Flaws that allow running it
outside a container, writing to the source, or leaking secrets are of particular interest.
